# 1.1.0

本次更新让投喂有机会被另一位自定义角色接走。每个角色拥有自己的参考图、人格和提醒，最终生成对应角色的点评与进食图。

- **多角色管理**：支持添加、复制、停用和删除，最多30个角色，每个角色支持主参考图和可选辅助图。
- **直观的概率设置**：平均分配只填总概率；自定义分配直接填各角色的最终概率，页面自动显示结果，合计超过100%不能保存。
- **抢饭提醒**：每个角色可自行填写，留空关闭。等图片生成完成后先发提醒，再紧接着发送点评和图片，不提前揭晓。
- **管理员指定测试**：使用 `#投喂角色 角色名` 并附带或引用食物图片，可补充情境说明。前缀跟随 AstrBot。
- **个人每日额度**：默认每群30次，每位用户在每个群内最多使用群上限的20%，默认每人6次；每天北京时间零点重置，管理员豁免。
- **其他优化**：调整抢饭表情与点评的对应关系；完善页面内确认和配置说明；压缩 logo 至1MB以内。

升级前备份配置和插件数据，覆盖更新即可，无需先卸载。已有角色、人设、参考图和概率设置会保留，旧单角色配置自动迁移；已保存的群额度不会自动改为30次，需要时请在后台手动调整。更新后请重新进入定制页面。

随机抢饭默认关闭。默认追加大肥鱼抢饭角色，附带参考图与人格，可在设置中修改或删除，删除后不会自动恢复；也可以自行添加其他角色。一次投喂仍只生成一张图，不因抢饭多扣一次额度。
