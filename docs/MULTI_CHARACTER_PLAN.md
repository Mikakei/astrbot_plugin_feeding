# 抢饭概率说明

适用于 v1.1.0 多角色抢饭功能。只想快速使用，选择“平均分配”，设置总抢饭概率即可。

## 分配方式

**平均分配（推荐）**

> 只需设置抢饭总概率。所有参与随机出场的角色平分机会，添加或停用角色后自动重新分配。

字段名称：**抢饭发生概率（%）**。

> 例如设置30%，原角色有70%的出场机会。添加三个参与角色后，每个抢饭角色各有10%的出场机会。

**自定义分配**

> 分别设置每个角色的出场概率。这里填写的是它在全部正常投喂中的概率，不是抢饭发生后的概率。剩余机会自动留给原角色。

角色字段名称：**每次投喂的出场概率（%）**。

> 例如大肥鱼15%、角色B 10%、角色C 5%，合计抢饭概率30%，原角色为70%。

自定义模式不再允许同时编辑总概率；总概率只显示自动计算的结果。

## 始终可见的结果预览

标题：**每次正常投喂，谁会出场？**

显示原角色及每个角色的最终概率，并注明：

> 每次独立随机，可能连续出现同一个角色。概率不是固定次数，不保证投喂100次恰好出现对应次数。

角色卡片可控制是否启用及是否参与随机；概率预览会提示配置不完整的角色。缺少参考图或人格时暂不参与随机。

## 增减角色与模式切换

- 平均分配：增减参与角色后重新平分，总抢饭概率不变。
- 自定义分配：新角色默认0%；停用角色后，其原有概率归还原角色，其他角色概率不变。保留停用角色的设置，重新启用前重新检查总和。
- 0%：不随机出现；已启用且配置完整的角色仍可由管理员指定测试。停用角色不可强制出场。
- 平均切换为自定义：填入当前各角色的最终概率，不改变分布。
- 自定义切换为平均：沿用当前合计抢饭概率，预览平均后的结果，保存后生效。
- 没有可参与的抢饭角色：普通投喂100%由原角色出场，并提示没有可随机出场的角色。
- 抢饭开关关闭：普通投喂100%使用原角色；保留用户填写的概率，重新开启时恢复。
- 每项接受0–100的有限数字；超过100%的配置不允许保存，不悄悄缩放用户输入。
- 超额提示示例：**抢饭概率合计为110%，超过上限10%。请降低部分角色的概率后保存。**
- 页面显示至多两位小数，可能因四舍五入存在尾差；实际计算保留原精度，不把显示值当作抽签值。

## 管理员测试说明

> 管理员可使用“命令前缀＋投喂角色＋角色名称”并附带或引用图片，指定角色出场。指定测试不受随机开关或概率影响，但仍遵循黑名单、冷却、队列及食物检查。

通用指令为 `#投喂角色 角色名称`；`#投喂大肥鱼` 兼容名称为“大肥鱼”的角色。
